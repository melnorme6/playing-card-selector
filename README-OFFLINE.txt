PLAYING CARD SELECTOR - OFFLINE VERSION

1. Extract the complete ZIP archive.
2. Open index.html in a current version of Chrome, Firefox, Edge, or Safari.
3. Keep the assets folder next to index.html.

Your collection is stored locally in the browser. Storage behavior for files opened directly from
the filesystem can vary between browsers. Export regular JSON backups from the application.

The offline application makes no automatic network requests. Its exported JSON contains only the
schema version, selected card identifiers, language, and theme.

For the most predictable experience, use the hosted version:
https://melnorme6.github.io/playing-card-selector/
